# Mission: Java 异步并发编程

## Why
借助当前 Java 21 / Spring DAG 聚合项目，形成能够迁移到其他 Java 项目的异步并发工程能力，而不是只记住 API 或只看懂一个仓库。

## Success looks like
- 能从源码推演调用线程、执行线程、任务、Executor、Future、等待点、共享状态和失败传播
- 能预测 DAG 的执行顺序、并行关系、耗时与异常行为，并用实验验证
- 能定位线程池饱和、共享状态、阻塞、超时、取消和背压问题
- 能正确解释并使用 CompletableFuture、平台线程、虚拟线程和并发限制
- 能独立实现并测试一个 100～200 行的简化 DAG 调度器

## Constraints
- 以 `cms-flow` 真实源码为主线，一次只解决一个核心问题
- 固定采用“源码 → 预测 → 执行过程 → 线程模型 → 原理 → 最小 Demo → 实验 → 回到源码”
- 先让学习者预测；连续两次无法推导时才完整揭示答案
- 掌握程度只通过代码预测、调试或修改实验升级，不以“感觉懂了”为依据

## Out of scope
- 第一阶段不展开缓存、Fallback、Resilience4j、虚拟线程和生产可靠性
- 不按目录顺序做源码 API 大全式讲解
